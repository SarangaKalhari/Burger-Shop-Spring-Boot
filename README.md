# 🍔 Burger Shop Management System

A RESTful Burger Shop Management System built using Spring Boot and Spring Data JPA.
This project demonstrates a layered architecture with proper separation of concerns and implements full CRUD operations for managing burger shop resources.

The application uses DTO–Entity mapping to ensure clean data transfer between layers and follows modern backend development practices for building scalable REST APIs.

## 🚀 Features

- ➕ Create new burger items

- 📋 View all available burgers

- 🔍 Retrieve burger details by ID

- ✏️ Update burger information

- ❌ Delete burgers from the system

- 🔄 DTO–Entity mapping

- 🧱 Layered architecture (Controller, Service, Repository)

- 🌐 RESTful API endpoints

## 🛠️ Technologies Used

- Java

- Spring Boot

- Spring Data JPA

- Hibernate

- MySQL / H2 Database

- Maven

- REST API

- API testing

## 🧠 Learning Objectives

- Building RESTful APIs using Spring Boot

- Implementing Spring Data JPA for database operations

- Using DTO–Entity mapping for clean architecture

- Applying layered architecture (Controller → Service → Repository)
